# Scoop bucket for gron

Install [vyrus001/gron](https://github.com/vyrus001/gron), a maintained fork of [tomnomnom/gron](https://github.com/tomnomnom/gron):

```powershell
scoop bucket add vyrus001 https://github.com/vyrus001/scoop-bucket
scoop install vyrus001/gron
```

Use the bucket prefix. Plain `scoop install gron` selects Scoop's upstream manifest.
